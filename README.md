# Transfer // Lab Transfer

A minimalist, high-speed in-lab file and text transceiver for local rooms and classrooms.

- **Instant Join:** Room-based communication (e.g. `CSE-LAB-302`).
- **Seat / Node HUD:** Visual seat numbering and active sender indicator.
- **Multi-File & Text Transfer:** Drag-and-drop file upload, folder selection, and real-time text beam.
- **Recipient Control:** Allow or block incoming transmissions.
